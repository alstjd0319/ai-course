# [스펙 문서] 주차 요금 계산기 (Parking Fee Calculator)

## 1. 개요
사용자가 차량의 입차 및 출차 시각을 입력하면 규정된 요금 체계에 따라 요금을 자동으로 산출하고, 당일의 결제 내역을 관리할 수 있는 단일 페이지 애플리케이션입니다.

## 2. 기능 요구사항 (Functional Requirements)

### 2.1 시간 입력 및 검증
- **입력 형식**: `HH:mm` (24시간제, 예: `09:30`, `23:59`)
- **검증 규칙**: 
    - 반드시 `출차 시각 > 입차 시각`이어야 함.
    - 만약 `출차 시각 <= 입차 시각`인 경우, 사용자에게 오류 메시지를 표시하고 계산을 중단함.

### 2.2 요금 계산 로직
- **기본 규칙**:
    - **무료 구간**: 주차 시간이 **30분 이하**인 경우 요금은 **0원**.
    - **과금 구간**: 30분을 초과한 시점부터 **10분당 500원** 부과.
    - **올림 처리**: 10분이 채 되지 않는 나머지 시간도 10분 단위로 간주 (Ceiling 적용).
- **한도 규칙**:
    - **일일 최대 요금**: 아무리 오래 주차해도 하루 최대 요금은 **20,000원**을 초과할 수 없음.

### 2.3 내역 관리 (CRUD)
- **추가 (Create)**: 계산 완료 시 `[입차, 출차, 주차 시간, 요금]` 정보가 목록에 추가됨.
- **조회 (Read)**: 하단 목록에 누적된 내역이 표시됨.
- **삭제 (Delete)**: 각 내역 옆의 [삭제] 버튼을 누르면 해당 내역이 삭제됨.
- **합계 (Aggregate)**: 목록 내 모든 요금의 합계를 계산하여 상단/하단에 실시간 표시.

### 2.4 UI/UX 요구사항
- **숫자 포맷**: 모든 금액은 천 단위마다 쉼표(`,`)를 포함함 (예: `1,500원`).
- **단일 페이지**: 별도의 페이지 이동 없이 모든 동작이 한 화면에서 이루어짐.

## 3. 상세 설계 (Technical Design)

### 3.1 요금 산출 공식 (Pseudo Code)
```javascript
function calculateFee(entryTime, exitTime) {
    const duration = exitTime - entryTime; // 분 단위
    
    if (duration <= 30) return 0;
    
    // 30분을 제외한 나머지 시간에 대해 10분 단위 올림 계산
    const taxableMinutes = duration - 30;
    const units = Math.ceil(taxableMinutes / 10);
    let fee = units * 500;
    
    // 최대 요금 20,000원 적용
    return Math.min(fee, 20000);
}
```
