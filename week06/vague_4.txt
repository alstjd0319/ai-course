전화번호를 어떤 형식으로 정리하고 싶으신가요? 보통 두 가지 케이스가 가장 많습니다.

1.  **하이픈(`-`)이 없는 숫자만 있는 경우** $\rightarrow$ `010-1234-5678` 형태로 만들기
2.  **형식이 제각각인 경우** (공백, 하이픈 혼용 등) $\rightarrow$ 하나로 통일하기

Python을 이용해 이 두 가지 상황을 모두 해결할 수 있는 함수를 만들어 보았습니다.

### Python 코드 예시

```python
import re

def format_phone_number(phone_str):
    """
    입력된 전화번호에서 숫자만 추출한 뒤, 
    휴대폰 번호 형식(010-XXXX-XXXX)으로 변환합니다.
    """
    # 1. 숫자 이외의 모든 문자 제거 (공백, 하이픈, 괄호 등 제거)
    digits = re.sub(r'\D', '', str(phone_str))
    
    length = len(digits)

    # 2. 길이에 따른 포맷팅
    if length == 11:
        # 010-1234-5678 형식
        return f"{digits[:3]}-{digits[3:7]}-{digits[7:]}"
    elif length == 10:
        # 010-123-4567 또는 02-123-4567 형식
        # 앞자리가 02이면 지역번호, 그 외에는 휴대폰 중간자리 3자리로 처리
        if digits.startswith('02'):
            return f"{digits[:2]}-{digits[2:5]}-{digits[5:]}"
        else:
            return f"{digits[:3]}-{digits[3:6]}-{digits[6:]}"
    elif length == 8:
        # 1234-5678 형식 (내선번호 등)
        return f"{digits[:4]}-{digits[4:]}"
    else:
        # 형식이 맞지 않으면 원래 숫자만 반환하거나 에러 처리
        return digits

# --- 테스트 코드 ---
test_numbers = [
    "01012345678",          # 숫자만 있음
    "010-1234-5678",        # 이미 되어 있음
    "010 1234 5678",        # 공백 있음
    "021234567",            # 서울 지역번호 (10자리)
    "(010)1234-5678",       # 특수문자 포함
    "0101234567",           # 10자리 휴대폰
    "12345678"              # 8자리
]

print(f"{'입력값':<15} | {'결과값'}")
print("-" * 30)
for num in test_numbers:
    print(f"{num:<15} | {format_phone_number(num)}")
```

### 코드 설명

1.  **`re.sub(r'\D', '', str(phone_str))`**: 
    *   정규표현식을 사용하여 숫자가 아닌 것(`\D`)을 모두 찾아 빈 문자열(`''`)로 바꿉니다. 
    *   이 과정을 거치면 `(010) 1234-5678` 같은 지저분한 문자열도 `01012345678`로 깔끔하게 정제됩니다.
2.  **조건문 (`if-elif`)**:
    *   **11자리**: 가장 일반적인 휴대폰 번호입니다. `3-4-4` 구조로 나눕니다.
    *   **10자리**: 서울 지역번호(`02`)인 경우 `2-3-5` 구조로, 그 외에는 `3-3-4` 구조로 나눕니다.
    *   **8자리**: 단순 번호의 경우 `4-4` 구조로 나눕니다.
3.  **F-string**: 파이썬의 최신 문법을 사용하여 문자열 사이에 하이픈을 직관적으로 넣었습니다.
