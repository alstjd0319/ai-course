전화번호를 어떤 형식으로 정리하고 싶은지에 따라 여러 가지 방법이 있습니다. 가장 대표적인 세 가지 상황(하이픈 제거, 하이픈 삽입, 숫자만 추출)에 대한 파이썬 함수 예시를 만들어 드릴게요.

### 1. 숫자만 남기고 모두 제거하기 (Cleaning)
사용자가 `010-1234-5678`, `010.1234.5678`, `010 1234 5678` 등 어떤 식으로 입력해도 숫자만 뽑아내는 함수입니다. 데이터베이스에 저장할 때 가장 많이 쓰입니다.

```python
import re

def clean_phone_number(phone):
    # 숫자가 아닌 모든 문자를 제거합니다.
    return re.sub(r'\D', '', str(phone))

# 테스트
print(clean_phone_number("010-1234-5678"))  # 01012345678
print(clean_phone_number("010.1234.5678")) # 01012345678
print(clean_phone_number("010 1234 5678")) # 01012345678
```

### 2. 표준 형식으로 만들기 (Formatting)
숫자만 있는 데이터를 `010-1234-5678` 형태로 보기 좋게 바꾸는 함수입니다. 한국 전화번호 패턴(3자리-4자리-4자리 또는 3자리-3자리-4자리)을 고려해야 합니다.

```python
import re

def format_phone_number(phone):
    # 1. 먼저 숫자만 추출합니다.
    numbers = re.sub(r'\D', '', str(phone))
    
    # 2. 길이에 따라 형식을 적용합니다.
    if len(numbers) == 11:
        # 010-1234-5678 형식
        return f"{numbers[:3]}-{numbers[3:7]}-{numbers[7:]}"
    elif len(numbers) == 10:
        # 02-123-4567 또는 010-123-4567 형식
        return f"{numbers[:3]}-{numbers[3:6]}-{numbers[6:]}"
    elif len(numbers) == 9:
        # 02-12-3456 형식
        return f"{numbers[:2]}-{numbers[2:4]}-{numbers[4:]}"
    else:
        # 형식이 맞지 않으면 원래 숫자 그대로 반환하거나 에러 처리
        return numbers

# 테스트
print(format_phone_number("01012345678"))   # 010-1234-5678
print(format_phone_number("021234567"))     # 02-123-4567
print(format_phone_number("010-123-4567"))  # 010-123-4567 (이미 되어있어도 유지)
```

### 3. 종합 선물 세트 (가장 추천하는 방식)
입력값이 무엇이든 **"일단 깨끗하게 만들고 -> 정해진 포맷으로 변환"**하는 실무형 함수입니다.

```python
import re

def standardize_phone(phone):
    """
    어떤 형태의 전화번호가 들어와도 '010-XXXX-XXXX' 형태로 통일합니다.
    """
    # 1. 숫자만 추출
    digits = re.sub(r'\D', '', str(phone))
    
    # 2. 유효성 검사 (너무 짧거나 긴 경우)
    if len(digits) < 9 or len(digits) > 11:
        return "Invalid Number"

    # 3. 패턴 적용
    if len(digits) == 11:
        return f"{digits[:3]}-{digits[3:7]}-{digits[7:]}"
    elif len(digits) == 10:
        return f"{digits[:3]}-{digits[3:6]}-{digits[6:]}"
    else:
        return f"{digits[:2]}-{digits[2:4]}-{digits[4:]}"

# 다양한 테스트 케이스
test_cases = [
    "01012345678",
    "010-1234-5678",
    "02.123.4567",
    "010 1234 5678",
    "0101234567",
    "123" # 잘못된 번호
]

for case in test_cases:
    print(f"{case}  =>  {standardize_phone(case)}")
```

### 사용 팁:
* **`re.sub(r'\D', '', phone)`**: 이 코드는 "Digit(숫자)이 아닌(`\D`) 것들을 찾아 빈 문자열(`''`)로 바꿔라"라는 뜻입니다. 즉, 특수문자와 공백을 한 번에 지워줍니다.
* **데이터 정제 목적**: 만약 엑셀이나 DB에 넣을 용도라면 **1번(숫자만 추출)** 방식을 사용하시고, 화면에 보여줄 용도라면 **3번(표준화)** 방식을 사용하세요.
