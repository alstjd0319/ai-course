# [기획서] 사용 기록 기반 앱 관리 매니저 (App Usage Manager)

## 1. 프로젝트 개요
### 1.1 배경
- 스마트폰 사용 시간이 늘어남에 따라 설치된 앱의 수가 급증함.
- 설치 후 거의 사용하지 않는 앱들이 저장 공간을 점유하여 용량 부족 문제를 야기함.
- 사용자가 직관적으로 '안 쓰는 앱'을 찾아 삭제할 수 있는 도구가 필요함.

### 1.2 목적
- 휴대폰에 설치된 앱 리스트를 사용자 사용 기록(Usage Stats) 순으로 정렬하여 제공.
- 사용 빈도가 낮은 앱을 빠르게 식별하고 즉시 삭제할 수 있는 환경 구축.

## 2. 주요 기능 (Core Features)
### 2.1 앱 리스트 스캔 및 데이터 수집
- 기기에 설치된 모든 앱 패키지 정보 가져오기.
- `UsageStatsManager`를 사용하여 앱별 최근 사용 시간/빈도 데이터 수집.

### 2.2 사용 기록 기반 정렬 (Sorting)
- **사용 시간순**: 앱별 총 사용 시간 기준 내림차순/오름차순 정렬.
- **최근 사용순**: 마지막으로 앱을 실행한 시점 기준 정렬.
- **미사용 앱 필터링**: 특정 기간(예: 최근 1개월) 동안 사용 기록이 없는 앱 분류.

### 2.3 앱 삭제 및 관리 (App Management)
- 리스트에서 앱 선택 시 삭제 기능 연결.
- 시스템 설정의 '애플리케이션 정보' 화면으로 이동하여 삭제를 유도하거나, Intent를 통한 삭제 프로세스 실행.

## 3. 기술 스택 (Technical Stack)
- **Platform**: Android
- **Language**: Kotlin (권장)
- **Minimum SDK**: API 21 (Lollipop) 이상 (UsageStats 접근을 위해 권장)
- **Key APIs**:
    - `PackageManager`: 설치된 앱 정보 획득.
    - `UsageStatsManager`: 앱 사용 통계 데이터 획득.
    - `Settings.ACTION_APPLICATION_DETAILS_SETTINGS`: 앱 삭제를 위한 설정 화면 이동.

## 4. 개발 단계 및 테스트/검증 계획 (Milestones & Testing)

| 단계 | 주요 작업 내용 | 테스트 및 검증 계획 (Testing & Verification) |
| :--- | :--- | :--- |
| **1단계: 환경 설정 및 권한 구현** | - 프로젝트 생성<br>- `PACKAGE_USAGE_STATS` 권한 선언 및 사용자 승인 로직 구현 | **[통합 테스트]**<br>- 권한 미허용 상태에서 앱 진입 시 권한 요청 플로우 작동 확인<br>- 권한 허용 페이지로의 Intent 이동 및 복귀 정상 여부 확인 |
| **2단계: 데이터 수집 엔진 개발** | - `PackageManager`로 앱 목록 로드<br>- `UsageStatsManager`로 앱별 사용 데이터 매핑 | **[단위 테스트 (Unit Test)]**<br>- 데이터 매퍼(Mapper) 클래스가 PackageName을 통해 올바른 UsageStats를 추출하는지 검증<br>- 앱 목록 데이터가 Null이 아닌 객체 리스트로 반환되는지 확인 |
| **3단계: UI/UX 구현** | - RecyclerView를 이용한 리스트 구현<br>- 정렬 필터(시간순, 최근순) UI 구성 | **[UI 테스트 (Espresso)]**<br>- 정렬 버튼 클릭 시 리스트 항목들의 순서가 기대값대로 변경되는지 검증<br>- 대량 데이터 로딩 시 스크롤 성능(Jank) 테스트 |
| **4단계: 삭제 기능 통합** | - 앱 삭제를 위한 Intent 연동<br>- 앱 상세 정보 페이지 이동 구현 | **[통합 테스트]**<br>- 특정 앱 항목 클릭 시 해당 앱의 `package_name`을 포함한 설정 화면이 정확히 호출되는지 확인 |
| **5단계: 최종 품질 보증 (QA)** | - 다양한 앱 환경에서의 테스트<br>- 메모리 누수 및 성능 최적화 | **[사용자 수락 테스트 (UAT)]**<br>- 실제 미사용 앱을 찾아 삭제하는 시나리오를 통한 UX 만족도 확인<br>**[성능 테스트]**<br>- Profiler를 통한 메모리 사용량 및 CPU 점유율 안정성 검증 |
